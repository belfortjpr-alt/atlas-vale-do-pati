# Atlas Vale do Pati

O **Atlas Vale do Pati** é um projeto de longo prazo dedicado a construir a base de conhecimento mais completa possível sobre o Vale do Pati, na Chapada Diamantina.

O projeto nasce com uma abordagem **data-first**: a prioridade é organizar, documentar, qualificar e consolidar os dados antes de qualquer aplicativo, interface ou produto final. O banco de dados e a rastreabilidade das informações vêm antes da experiência de uso.

No futuro, esta base poderá sustentar diferentes interfaces, como um **Atlas** voltado a estudo, pesquisa e consulta aprofundada, e um **Explorador** voltado ao uso em campo. Essas interfaces, porém, não fazem parte desta fase inicial.

Nesta etapa, o repositório existe para estabelecer uma estrutura profissional de documentação e organização de dados. Ainda não há implementação de funcionalidades, banco de dados, APIs, frontend ou backend.

## Objetivos

- Centralizar documentação sobre a visão, o escopo e a evolução do projeto.
- Separar dados brutos, dados processados, esquemas e registros de fontes.
- Priorizar a construção de uma base de dados reutilizável, rastreável e independente de interfaces específicas.
- Manter o projeto aberto a futuras decisões técnicas sem antecipar escolhas de arquitetura.
- Favorecer contribuições cuidadosas, rastreáveis e alinhadas ao contexto territorial do Vale do Pati.

## Estrutura do repositório

```text
docs/                 Documentação conceitual e diretrizes do projeto
data/raw/             Dados brutos preservados como recebidos ou coletados
data/processed/       Dados tratados, normalizados ou derivados
data/reference/       Cadastros de referência do Atlas
data/schemas/         Esquemas e contratos de dados futuros
data/sources/         Registros sobre origem, licença e contexto das fontes
scripts/              Espaço reservado para automações futuras
assets/               Materiais visuais e estáticos futuros
```

## Estado atual

Este repositório está em fase de fundação. As decisões sobre formatos finais de dados, ferramentas, infraestrutura e aplicações serão tomadas de forma incremental, documentada e revisável.
