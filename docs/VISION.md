# Visão

O Atlas Vale do Pati pretende se tornar uma infraestrutura aberta e organizada de dados geográficos sobre o Vale do Pati, respeitando a complexidade ambiental, cultural, histórica e social do território.

A visão do projeto é construir a base de conhecimento mais completa possível sobre o Vale do Pati, reunindo informações de forma responsável, com documentação clara sobre origem, contexto, limitações, conflitos e possíveis usos dos dados.

O projeto deve permitir que futuras aplicações, análises e visualizações sejam construídas sobre uma base sólida, sem comprometer a rastreabilidade ou a qualidade da informação.

## Princípios

- Dados acima da interface.
- Toda informação deve ser rastreável até sua fonte.
- Hipóteses devem ser claramente diferenciadas de fatos confirmados.
- Nenhuma informação será descartada; conflitos serão documentados.
- O banco de dados deve ser reutilizável por diferentes aplicações.
- Respeito ao território e às comunidades relacionadas ao Vale do Pati.
- Rastreabilidade das fontes e das transformações aplicadas aos dados.
- Evolução incremental, evitando decisões técnicas prematuras.
- Organização simples, clara e sustentável para um projeto de longo prazo.
- Abertura para colaboração responsável e revisão contínua.
