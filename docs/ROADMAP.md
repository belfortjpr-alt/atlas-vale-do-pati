# Roadmap

Este roadmap apresenta apenas a ordem inicial de evolução do projeto. Os detalhes de cada etapa serão definidos conforme o projeto amadurecer.

## Milestone 1 — Fundação do repositório

- Estabelecer a estrutura documental e organizacional inicial.

## Milestone 2 — Inventário completo das fontes

- Levantar e registrar fontes de dados geográficos, bibliográficos, históricos e de campo.

## Milestone 3 — Modelagem conceitual do território

- Definir uma visão conceitual das entidades, relações e níveis de incerteza do território.

## Milestone 4 — Consolidação dos dados geográficos

- Organizar dados brutos, dados processados, fontes, conflitos e lacunas conhecidas.

## Milestone 5 — Ferramentas de importação e validação

- Criar mecanismos futuros para importar, validar e auditar dados de forma consistente.

## Milestone 6 — API de consulta

- Disponibilizar acesso estruturado aos dados consolidados quando a base estiver madura.

## Milestone 7 — Atlas

- Desenvolver uma interface futura para estudo, pesquisa e consulta aprofundada.

## Milestone 8 — Explorador

- Desenvolver uma interface futura voltada ao uso em campo.
