# Modelo de dados

Este documento registra uma visão geral inicial para orientar discussões futuras sobre o modelo de dados do Atlas Vale do Pati.

O projeto deverá representar informações geográficas e contextuais do território de forma rastreável, extensível e compatível com diferentes usos futuros. Neste momento, nenhuma estrutura definitiva, tecnologia de armazenamento, formato de arquivo ou esquema final está definido.

## Possíveis categorias conceituais

- Lugares e pontos de interesse.
- Trilhas, caminhos e conexões territoriais.
- Elementos naturais, como rios, serras, vales e formações relevantes.
- Áreas, limites e recortes geográficos.
- Fontes de dados, referências e metadados.
- Informações históricas, culturais ou contextuais quando houver fonte adequada.

## Entidades previstas

- Rio
- Cachoeira
- Poço
- Trilha
- Waypoint
- Mirante
- Formação geológica
- Casa de apoio
- Camping
- Fonte bibliográfica
- Tracklog
- Fotografia
- Observação de campo

## Diretrizes iniciais

- Todo dado deve poder ser associado a uma fonte documentada.
- Transformações devem ser registradas de forma compreensível.
- O modelo deve permanecer flexível até que os requisitos estejam mais claros.
- A precisão, a escala e as limitações dos dados devem ser consideradas parte essencial do modelo.
